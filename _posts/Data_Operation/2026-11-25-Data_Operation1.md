## 데이터 운영이란?

데이터를 **수집 → 저장 → 가공 → 제공**하는 전 과정이 끊기지 않고, 믿을 수 있는 상태로 계속 돌아가게 관리하는 일이다.
한 번 분석하고 끝나는 것이 아니라, 데이터가 **지속적으로 좋은 품질로 흘러가도록** 유지하는 데 초점이 있다.

### 1. 용어 정리

 - **데이터 운영(Data Operations)** : 데이터 파이프라인과 품질, 접근 권한, 장애 대응을 포함해 데이터를 안정적으로 굴리는 활동
 - **데이터 파이프라인** : 원천 데이터가 저장소와 분석 환경까지 이동하고 가공되는 흐름
 - **데이터 품질(Data Quality)** : 정확성, 완전성, 일관성, 적시성 등 데이터가 쓸 만한 정도
 - **데이터 거버넌스** : 누가 어떤 데이터를 어떤 규칙으로 쓰는지 정한 정책과 체계
 - **메타데이터** : 데이터에 대한 설명 (출처, 컬럼 의미, 갱신 주기 등)

### 2. 주요 업무

| 영역 | 하는 일 | 예시 |
|---|---|---|
| 수집 | 원천 데이터를 가져온다 | DB 추출, API 호출, 파일 업로드 |
| 적재/가공 | 정제하고 변환해서 저장한다 | 결측치 처리, 형식 통일, 중복 제거 |
| 품질 관리 | 데이터가 맞는지 검증한다 | 건수 대조, 값 범위 확인, 중복 검사 |
| 모니터링 | 파이프라인이 잘 도는지 본다 | 실패 알림, 지연 확인, 현황 대시보드 |
| 접근 관리 | 권한과 보안을 관리한다 | 계정별 권한, 개인정보 마스킹 |
| 문서화 | 데이터 의미와 규칙을 기록한다 | 데이터 사전, 변경 이력 |

### 3. 데이터 품질 기준

 1. **정확성** : 실제 값과 일치하는가
 2. **완전성** : 빠진 값이 없는가
 3. **일관성** : 시스템마다 같은 값이 같은 형식인가
 4. **유일성** : 중복 데이터가 없는가
 5. **적시성** : 필요한 시점에 최신 상태인가

### 4. 품질 검증 예시 (Python)

```python
import pandas as pd

df = pd.read_csv("data.csv")

# 결측치 비율
print(df.isnull().mean())

# 중복 행 개수
print(df.duplicated().sum())

# 값 범위 확인 (예: 나이는 0~120)
print(df[(df["age"] < 0) | (df["age"] > 120)])
```

### 5. 운영 시 체크리스트

 - [ ] 데이터가 정해진 주기에 맞춰 들어오는가
 - [ ] 원천 건수와 적재 건수가 일치하는가
 - [ ] 실패했을 때 알림이 오는가
 - [ ] 컬럼 의미와 갱신 규칙이 문서로 남아 있는가
 - [ ] 권한이 필요한 사람에게만 열려 있는가

### 6. 정리

 - 데이터 운영은 **분석 이전에 데이터를 믿을 수 있게 만드는 일**이다.
 - 핵심은 **품질 검증, 모니터링, 문서화** 세 가지다.
 - 다음 글에서는 실제 검수/현황 관리 방법을 더 구체적으로 정리할 예정이다.
